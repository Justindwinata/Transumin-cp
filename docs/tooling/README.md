# Development and AI-Agent Tooling

The repository preserves Taste Skill from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) in `.agents/`, with lock information in `skills-lock.json`. This is approved development and AI-agent tooling, not an application runtime dependency. It must not be imported into product code or treated as an npm/package dependency.

`design-taste-frontend` is the approved default frontend craft skill. Other installed style-oriented skills remain dormant unless the Product Owner explicitly authorizes their use. Agents must not mix competing visual directions automatically.

Project authority remains: latest Product Owner instruction, frozen specifications, verified implementation evidence, then tooling guidance. A skill can improve layout, typography, spacing, hierarchy, motion, accessibility, and implementation craft, but cannot redefine product scope, information architecture, map-first behavior, evidence semantics, responsive requirements, performance requirements, ownership, or research methods.

Skill version updates require deliberate review of the source, lock change, behavioral impact, and compatibility with project rules. Phase 0.1 preserves the installed version without upgrade. No skill may fabricate product data, official sources, realtime state, KPIs, screenshots, experiment results, or research facts.
